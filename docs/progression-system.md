# 武将养成系统设计（升级 + 碎片 + 被动技能）

> 子文档，详细设计见此；全局进度表见 `../DESIGN.md`。对应需求 **R9**。

---

## 一、两条成长线（务必区分）

| | 升星（已实现，R8） | 升级（本需求 R9） |
|---|---|---|
| 路径 | 战斗中招贤抽到重复 | 花**专属武将碎片**养成 |
| 范围 | **单局内**，每关重置 | **永久**，存档保留 |
| 等级 | 1→3（招贤池满级排除） | 1→5 |
| 作用 | 在基础属性上临时提升 | 决定武将**进关时的基础属性** + 解锁被动 |
| 材料来源 | — | **通关奖励（专属碎片）** |

**属性计算顺序**：`基础属性 ×(1+升级加成) → 升星缩放 → 羁绊加成`。
- 升级加成：每级 +8% 伤害、+3% 射程（Lv1 为基准=现状，Lv5≈+32% 伤害）。
- 升星：沿用现有 towerStats 的 level 缩放，不变。

---

## 二、专属碎片 + 升级

- 每个武将有独立碎片计数（持久化），如 `关羽碎片 ×12`。
- **碎片来源**：通关掉落，按关卡配置（可重复刷）。`LEVEL.shardRewards = { guanyu: 3, zhangfei: 2 }`。
- **升级消耗**（累计到目标等级所需碎片，配置 `TUNING.rankCost`）：

| 目标等级 | Lv2 | Lv3 | Lv4 | Lv5 |
|---|---|---|---|---|
| 碎片 | 4 | 8 | 14 | 22 |

- **被动解锁**：升级达到 **Lv3** 解锁该武将唯一被动（永久，之后每战生效）。

碎片在 3 个关卡的初步分配（R11 加关卡后补全 8 将覆盖）：
- 虎牢关 → 关羽+3、张飞+2
- 官渡 → 刘备+2、黄忠+2、马超+1
- 赤壁 → 诸葛亮+3、庞统+2、赵云+2

## 三、被动技能框架

被动配置在 `data.js` 的 `HERO.passive = { name, unlockRank:3, type, params, desc }`。
战斗中按钩子类型派发：

| 钩子 type | 触发 | 实现点 |
|---|---|---|
| `onHit` | 该武将攻击命中敌人时 | damage 派发前/后 |
| `onKill` | 该武将击杀敌人时 | damage 致死时 |
| `aura` | 常驻光环（自身/相邻友军） | recomputeBonds 同步计算 |
| `modifier` | 常驻属性改算（如远距增伤） | towerStats 内 |

### 八将被动（均 Lv3 解锁）

| 武将 | 被动 | 类型 | 效果 |
|---|---|---|---|
| 刘备 | 仁德 | aura | 相邻友军伤害 +12% |
| 关羽 | 武圣 | onHit | 15% 暴击（2 倍伤害） |
| 张飞 | 燕人咆哮 | onHit | 25% 概率短暂眩晕命中目标 |
| 马超 | 西凉铁骑 | onHit | 命中附带 1.5s 减速 |
| 黄忠 | 百步穿杨 | modifier | 目标越远伤害越高（最高 +40%） |
| 庞统 | 连环计 | modifier | 自身溅射半径 +40% |
| 赵云 | 龙胆 | onHit | 攻击附带小范围溅射 |
| 诸葛亮 | 八阵图 | onKill | 火攻击杀触发二次小爆 |

> 攻击者归属：projectile / 瞬时命中需带 `ownerHero`，以便派发被动。

## 四、养成界面

- 主菜单加「养成」入口（与「图鉴」并列）。
- 列出全部武将：头像/星级/当前升级等级/专属碎片数/被动解锁状态/「升级」按钮（碎片足够才可点）。
- 升级即时写存档；被动解锁后在该武将行高亮显示。
- 数据来自 GameData + 存档，新增武将自动出现。

---

## 五、存档扩展

`sgtd_save_v1` 增加字段（loadSave 容错补默认）：
```
{ maxUnlocked, shards: { guanyu: 12, ... }, ranks: { guanyu: 3, ... } }
```
- `shards[id]`：专属碎片数，默认 0。
- `ranks[id]`：升级等级，默认 1。

## 七、验收标准

1. 通关掉落专属碎片并写存档，重载持久。
2. 养成界面可花碎片升级武将（1→5），升级影响进关基础属性。
3. 升级达 Lv3 解锁被动，战斗中正确触发（暴击/眩晕/减速/光环等）。
4. 升星（招贤）与升级（养成）两条线叠加正确，公式顺序无误。
5. 被动/碎片/升级全部配置在 data.js，加武将只改配置。
6. 无 console 报错。

## 八、平衡说明

meta 升级是**永久变强**机制，会让老玩家逐渐碾压固定关卡（养成游戏的预期）。Lv1 = 现状平衡（新玩家体验不变），Lv5 适度增强而非破坏。被动强度走"锦上添花"而非"质变"，避免一被动定胜负。
