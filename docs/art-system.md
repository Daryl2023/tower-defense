## 二、可替换架构（设计核心）

### 2.1 Sprite 抽象层

新增渲染抽象，所有"画一个角色"的调用都走它，而非直接画几何图形：

```
drawSprite(ctx, spriteId, x, y, opts)
  opts: { size, facing, frame, scale, flash }
```

- `spriteId`：如 `hero:guanyu` / `enemy:infantry`。
- 内部根据 **SPRITE_SOURCE** 决定走哪条渲染路径：
  - `"proc"`（默认）：调用 `ProceduralSprites[spriteId](ctx, ...)` 程序化绘制。
  - `"image"`：从 `ImageAssets[spriteId]` 取已加载的 `Image`/精灵图绘制。

### 2.2 资源清单（替换入口）

集中定义一张表，替换时只动这里：

```
const SPRITE_ASSETS = {
  "hero:liubei":   { img: null, /* 后期填 'assets/liubei.png' */ frames: 1 },
  "hero:guanyu":   { img: null, frames: 1 },
  ...
};
```

- `img === null` → 自动回退到程序化绘制。
- 用户提供图片：把路径填入 `img`，系统预加载后自动切换，无需改渲染调用点。

### 2.3 替换流程（写给未来）

1. 把图片放入 `assets/`（如 `assets/guanyu.png`）。
2. 在 `SPRITE_ASSETS["hero:guanyu"].img` 填路径。
3. 刷新即生效；程序化版本作为加载失败兜底。

## 三、形象设计（程序化占位图）

每个角色 = 圆形底盘 + 头部 + 标志性特征（头盔/冠/巾）+ 武器/兵器剪影 + 阵营色。
辨识靠**配色 + 武器形状 + 头饰**三要素。

### 3.1 武将

| 武将 | 阵营色 | 头饰特征 | 武器特征 | 备注 |
|---|---|---|---|---|
| 刘备 | 蜀·杏黄 | 主公冠（双带） | 双股剑（细） | 主公气质 |
| 关羽 | 蜀·墨绿 | 长髯 | 青龙偃月刀（大刀剪影） | 红脸长髯最具辨识 |
| 张飞 | 蜀·玄黑 | 虬髯/豹头 | 丈八蛇矛（长枪带蛇头） | 黑甲 |
| 诸葛亮 | 蜀·素白 | 纶巾 | 羽扇（扇形） | 文士袍 |

### 3.2 小兵 / Boss

| 单位 | 配色 | 特征 |
|---|---|---|
| 步兵 | 灰褐 | 圆盾 + 短刀，普通头盔 |
| 骑兵 | 赭黄 | 马形底座 + 长枪，跑动姿态 |
| 攻城车 | 木褐 | 方形车体 + 轮子 + 撞角，体型最大 |

## 四、动画设计

统一用 `game.time` 驱动，避免每对象存帧；动画 = 时间的函数。

| 动画 | 触发 | 表现 | 实现 |
|---|---|---|---|
| 待机呼吸 | 常态 | 角色轻微上下浮动 + 缩放脉动 | `sin(time*k + phase)` 偏移 |
| 攻击动作 | 开火瞬间 | 武器朝目标挥动/后坐，0.15s 回弹 | 塔记 `attackAnim` 计时，按目标角度偏移武器 |
| 行走踏步 | 敌人移动 | 身体左右小幅摆动 | `sin(time*speedK)` |
| 受击 | 命中 | 白色闪光 + 轻微缩放 | 敌人记 `hitFlash` 计时，叠加白色 alpha |
| 死亡 | hp<=0 | 缩小+淡出消散（已有飘字保留） | 加 `dying` 过渡，0.25s |

## 五、战斗特效

| 特效 | 场景 | 表现 |
|---|---|---|
| 弓箭拖尾 | 弓兵子弹 | 细长箭形 + 淡拖尾 |
| 枪刺火花 | 枪兵瞬时命中 | 命中点星形迸射 |
| 火攻溅射 | 诸葛亮/火计 | 橙红火球 + 范围灼烧环（已有 blast 升级） |
| 命中爆点 | 任意命中 | 小粒子四溅 |
| 火计大招 | 施放火计 | 多层火焰扩散环 + 余烬粒子 |
| 空城计大招 | 施放空城计 | 紫色疑兵迷雾扩散 + 问号符 |

粒子统一用轻量 `particles[]` 池，`{x,y,vx,vy,life,color,size}`，在主循环更新+绘制。

## 七、验收标准

1. 四武将与三小兵在画面上**互相可区分**（不靠文字标签也能认出大致角色）。
2. 开火、命中、死亡有可见动画反馈。
3. 火计/空城计有区别明显的大招特效。
4. **可替换性验证**：在 `SPRITE_ASSETS` 填入一张测试图片后，对应角色切换为图片渲染，且移除后自动回退程序化。
5. 帧率稳定（粒子有上限，无明显卡顿）。
6. 无 console 报错。
