## 二、需求与设计

### R-ART-ZY-01 赵云图片资产

**需求描述**

为蜀汉武将赵云制作三类游戏图片资产：

- 8 帧动作精灵表：2 行 4 列等分网格，Q 版 2.5 头身，3/4 朝右，银白主色，银盔白缨，白袍银甲，亮银枪，透明 PNG-32。
- UI 立绘：全身英武站姿，3/4 朝右，白袍银甲银盔，手持亮银枪，可带极淡银蓝脚底光晕，透明 PNG-32。
- 技能图标组：6 个方形图标，2 行 3 列，赵云主题，银白主色、金色描边，透明 PNG-32。

**设计方案**

- 采用程序化 2D 绘制生成，避免可见背景、文字、水印和棋盘格。
- 精灵表画布尺寸为 1024 x 512，每格 256 x 256；角色与武器控制在各自格子内，保留至少约 15% 格宽透明间隙，脚底对齐。
- 立绘画布尺寸为 640 x 896，角色居中偏下，完整保留枪、盔、白缨、白袍银甲轮廓。
- 技能图标画布尺寸为 768 x 512，每格 256 x 256，6 个独立图标，外部区域 alpha=0。
- 输出均使用 RGBA PNG，文件带透明通道。

**涉及文件/模块**

| 文件 | 用途 |
|------|------|
| `赵云/赵云精灵表.png` | 赵云 8 帧动作精灵表 |
| `赵云/赵云立绘.png` | 赵云 UI 立绘 |
| `赵云/赵云技能.png` | 赵云 6 技能图标组 |
| `赵云/preview.html` | 浏览器检查透明背景与排版的预览页 |

**验收标准**

- 三张最终 PNG 均为 RGBA，角落与背景区域 alpha=0。
- 精灵表严格 2 行 4 列，每帧角色不越界、不贴边，脚底基本对齐。
- 立绘无场景、无地面、无棋盘格、无灰白底，人物完整可辨。
- 技能图标为 2 行 3 列，6 个图标独立可辨，外部透明。
- 使用浏览器预览检查图片可正常加载，无 console 报错。
